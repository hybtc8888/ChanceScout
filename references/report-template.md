# 每期简报模板

每期按下面的模板交付；有文件能力时保存为本轮目录的 `report.md`，聊天中给出摘要和链接。三路覆盖表始终保留，不因某一路条目充足而省略其余两路。

- 按当前配置分别检索公开机会、小红书和 Reddit。用户明确不启用的来源仍列在覆盖表，写明原因。
- 状态写“有结果”“无合适结果”“受阻”或“未检索”。只有实际检索后才能写“无合适结果”；受阻或未检索时说明阶段、原因与实际检查到哪里。
- 覆盖表记录检索范围、实际核验的项目或原帖数，以及进入下方主推荐的条数。搜索卡片与原帖分开计数；未取得的数量不填成0。
- 不设来源配额、保底条数或固定比例。`research.target_total`仅为整期推荐数量的参考，不是凑数要求，也不代替其余来源的检索。
- 主推荐分公开机会、有偿任务、产品需求，各组按时效和可行动性排序；无合适条目就写明。受限、证据不足和排除项单列，不计入主推荐。
- 每条来源可回查，保留时间、收益或预算、地区与资格、未知项和下一步。没有金额就写未知，不能据缺失信息推断资格、成交或剩余名额。
