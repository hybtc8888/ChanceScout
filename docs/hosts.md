# 部署与偏好

共享入口是根目录的 `SKILL.md`；按任务读取它链接的研究与记录说明。

| 宿主能力 | 运行方式 |
|---|---|
| 联网、读原页、可写文件、Python | 完整研究并使用本地归档工具 |
| 联网、读原页、可写文档 | 研究并维护相同 JSON 与历史含义 |
| 联网、读原页，无持久存储 | 交付单次简报与可保存 JSON，说明未做跨次去重 |
| 只能读用户材料 | 整理材料，标出未实时核验的部分 |

Codex 可安装技能；Dot 可复用其已连接电脑上的工作目录；Muse 等助手读取同一入口。具体联网、账号和存储能力以实际执行任务为准，不能从产品名称推定。当前已验证本地 Codex 的小红书与 Reddit 研究、本机 Dot 经花叔 MCP 入口的小红书研究和截图，以及本地 Python 工具；Muse 尚未实测。

需要复用登录状态时，推荐可选安装 huashu-chrome；其他可用浏览器工具同样可以使用。连接步骤和可复制的本机交接要求见 [浏览器接入](browser.md)。

## 首次部署与偏好调整

由接手助手询问一次，可全部留空：

```text
关注哪些方向？接受哪些地区及远程/线下方式？
希望看多久以内的需求？默认近7天，可以改成近24小时等。
可直接跳过，先返回不限方向、地区的泛用结果，以后随时调整。
```

有持久存储时保存到用户的 `config.json` 或等价文档；否则直接用于本次，并交付可保存配置。未提供设置也执行真实检索，不停在等待表单。

- `setup_status`：模板为 `unconfigured`，跳过设定后为 `generic`，自定偏好后为 `custom`。
- `focus`、`regions`：空数组代表不限，不补入默认行业或用户所在地。
- `work_mode`：`any` / `remote` / `onsite` / `hybrid`。
- `workspace`：两类历史的共用目录，相对配置文件所在目录解析，默认 `chancescout-data`。
- `research.recent_days`：付费需求时效，默认7天。公开机会另按实际参与窗口核验。
- `demand.sources`：默认小红书与 Reddit；缺少某来源的可用访问能力时标出未完成部分。

用户可直接说“只看上海、允许远程”“改为近24小时”“恢复不限方向”。只改其明确提出的设置，其余偏好、ID、备注和历史保留；每次简报开头说明实际采用的条件。

迁移到别的电脑或助手时，带上工作流、配置和两类历史文件，并确认目的宿主能读写。磁盘路径不会自动变成云端可访问资料。不要复制登录凭据或为了接入暴露本地服务。

这些偏好由助手用于检索和判断；Python 工具没有独立的交互部署表单、搜索过滤器或定时器。
