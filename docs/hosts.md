# 宿主接入

共享工作流按能力适配，不依赖某一个产品的私有接口。

| 场景 | 怎么接 | 记录在哪里 |
|---|---|---|
| Codex 本地 | 安装完整技能或读取仓库，使用已有搜索和文件工具 | 用户指定工作目录 |
| Dot + 已连接电脑 | 让 Dot 继续本地 Codex 工作，复用技能和历史路径 | 连接电脑上的同一工作目录 |
| Muse 等联网助手 | 发送 README 中的任务和 SKILL.md 链接，先检查宿主能力 | 宿主提供的文件/文档存储；没有则单次模式 |
| 可联网但不能运行代码 | 助手读取协议，自行维护相同 JSON 和简报 | 宿主可写存储 |
| 仅能读用户材料 | 按材料整理机会与待核验项 | 当前输出；不声称实时搜索 |

## 交接时最少带上

- 仓库链接或完整工作流文件。
- 本次方向、地域或身份等主动提供的条件。
- 既有历史文件/文档位置；新环境要实际复制或授权访问它。
- 手动还是定时。默认手动，定时由宿主另行配置。

本地磁盘路径不会因为发给云端助手就自动变得可读。若换电脑或产品，先迁移历史，再更新原来的记录；不能建立一份空历史后声称已经去重。

## 支持范围与测试状态

本项目的前身已在本地 Codex 完成真实公开信息检索试跑。用户反馈部署实验成功；这里不据此宣称 Dot 或 Muse 的所有账号、浏览器和存储路径均已验证。

仓库版本对 Python 文件处理提供自动测试；GitHub Actions 的结果是对应系统上的实际证据。具体宿主的联网和文件权限需要在自己的环境中检查。欢迎在 issue 中提供产品、日期、可用工具与去除个人信息的复现步骤。

## 默认行为

读取公开信息、产生简报和本次记录。报名、投稿、付款、发信和定时通知由用户另行决定。不要为了适配宿主而暴露本地服务或复制浏览器登录资料。
