# 浏览器接入

助手需要能读取目标页面。已有可用浏览器工具时直接使用；需要复用 Chrome 登录状态时，推荐可选安装 [huashu-chrome](https://github.com/alchaincyf/huashu-chrome)。不使用 Chrome 也能运行 ChanceScout，按实际可访问的来源交付。

## 安装花叔扩展

这条可选路线使用 Chrome、Node.js 20+ 和支持本机 MCP 的宿主。按 [上游安装说明](https://github.com/alchaincyf/huashu-chrome#安装) 执行：

```bash
npx huashu-chrome install
npx huashu-chrome doctor
```

安装器会检测支持的客户端并配置 MCP；按引导由用户完成扩展安装，在同一 Chrome 配置文件里登录目标网站。`doctor` 用于检查本地服务与扩展连接，可能启动本地桥；连接正常后仍要做下面的页面验收。未识别的宿主按上游说明及宿主实际支持的入口配置，不能假定 Dot、Muse 会自动获得工具。

扩展能使用浏览器中的现有登录状态，启用前查看 [上游隐私说明](https://github.com/alchaincyf/huashu-chrome/blob/master/PRIVACY.md)。本项目仅执行用户要求的研究，不会因安装扩展而自动联系、发布或定时运行。

## 首次连接验收

1. 在实际执行研究的任务中检查可用工具，新建自己的后台标签，记录本轮标签 ID；不接管其他任务页面。
2. 先读一个普通公开网页的正文，再读目标网站的搜索页或首页。分别记录调用方法、耗时与失败阶段；能列标签或导航不等于能读正文。
3. 需要图片证据时，确认目标图片加载后截图并实际查看。保存成功不等于画面完整；首页验收也不等于已经研究原帖。

花叔工具按其说明先读取站点 `learnings`，后续调用显式传 `tabId`。不同任务不复用旧报告里的数字 ID。

## 交给 Dot 或同类助手

把下面的要求与研究任务一起发送，将工作目录替换为实际路径：

```text
连接我的本机，在我指定的 ChanceScout 工作目录执行，读取 SKILL.md、配置和历史。
实际检查本任务可用的浏览器工具，并验证正文及必要截图，不沿用其他会话的标签或旧结果。
需要复用 Chrome 登录状态时，可推荐 huashu-chrome；已有工具可用就直接运行。
没有直接浏览器工具时，仅在宿主支持的标准 MCP 入口可用时连接已安装的本地服务。
需要命令授权时使用该宿主正式审批入口；没有可用入口就报告缺口，不修改全局权限。
按现有偏好分别研究公开机会、小红书和 Reddit，按 references/report-template.md 汇总。
三路都说明本轮结果或缺口，不因某一路结果充足跳过其他来源，不硬凑条数或比例。
保持手动，不联系、发布、付款或建立定时任务。
```

项目会话、本机 Dot 任务和云端任务可能拿到不同工具。磁盘路径、扩展安装或登录状态不会自动让另一宿主获得浏览器访问能力。

## 读取或截图异常

| 现象 | 如何处理 |
| --- | --- |
| 工具未提供 | 报告工具缺失；检查宿主实际支持的本机 MCP 入口。不能归因为页面超时或未登录。 |
| 列标签、导航成功，正文和截图超时 | 用普通公开页做一次短对照；普通页也失败时，先检查读取链路和工具进程的联网情况。 |
| 项目可用，Dot 不可用 | 对比实际工具、连接的电脑与浏览器配置文件、标签归属，以及本地服务访问权限。 |
| JPEG/PNG 有空白或模糊封面 | 检查页面图片是否已加载；只依据实际可读内容记录证据。 |
| 截图报 `Detached while handling command` | 记录扩展版本和完整错误，核查操作中是否发生空闲断开；按上游更新及排障说明处理。 |

本机曾复现：浏览器工具进程没有使用既有代理，正文与截图出现约21/42秒等待；仅调整该工具进程使用现有代理后恢复，TUN保持关闭。这是特定环境的排查记录，不是所有超时的通用原因，也不是部署要求。保留浏览器正式安全检查，不以延长超时冒充修复。

截至2026-10-28，本机 Dot 经花叔入口已取得小红书正文和完整 PNG；同轮 Dot 未提供原生浏览器接口，未将其计为通过。相关机器专属代理补丁、修改版扩展、账号资料和截图留在本地，仓库不分发；其他电脑仍需按实际版本验收。
