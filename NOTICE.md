# Provenance

This repository independently implements an evidence-linked opportunity research workflow. An earlier local evaluation used a user-supplied archive named `opportunity-radar.zip`; that archive did not identify a redistributable license.

The archive, its original text, the machine-specific adaptation, private profiles, and real local run records are not distributed here. Repository instructions, helper code, schemas, tests and fictional fixtures were written for this public project. The MIT license covers these repository files, not third-party announcements or assets that a user may research.
